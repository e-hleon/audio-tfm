# Audio TFM

Plataforma local-first para la generación de un diario personal a partir de
interacciones de voz.

El sistema procesará grabaciones de audio mediante reconocimiento automático del
habla y modelos de lenguaje para obtener transcripciones, resúmenes, temas,
decisiones, tareas y recordatorios.
